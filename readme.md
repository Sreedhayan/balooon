# Balloon Dodge

A fast-paced HTML5 canvas game where you dodge falling obstacles as a balloon.

## Features

- Smooth mouse/touch controls
- Three power-up types: Shield, Slow-Mo, Bonus Points
- Progressive difficulty
- Persistent high score (localStorage)
- Particle effects & glow visuals

## Play

Open `baloon.html` in any modern browser. No build step required.
